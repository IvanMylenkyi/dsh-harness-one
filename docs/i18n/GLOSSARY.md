# Workflow One English glossary

This glossary is the source of truth for user-facing English copy. Use sentence
case and short imperative labels for actions.

| Chinese concept | English term | Notes |
| --- | --- | --- |
| 工作流 | Workflow | A saved graph definition. |
| 运行 | Run | One execution of a workflow. |
| 尝试 | Run attempt | A retry or resumed execution of a node/run. |
| 节点 | Node | A step in a workflow graph. |
| 画布 | Canvas | The graph editor. |
| 连线 | Edge / connection | Use “edge” in graph-specific copy and “connection” in UI actions. |
| 输入 | Input | Data entering a node or workflow. |
| 输出 | Output | Data emitted by a node or workflow. |
| 智能体 | Agent | A dsh-backed agent node. |
| 条件 | Condition | A branching node. |
| 消息通知 | Notification | A node or delivery event. |
| 触发器 | Trigger | Manual, webhook, or schedule entry point. |
| 定时任务 | Schedule | A saved recurring trigger. |
| 成果 | Result | User-facing output of a run. |
| 过程 | Process | Timeline and intermediate execution details. |
| 问题 | Issue | Actionable problem shown to the operator. |
| 产物 | Artifact | A file or deliverable generated by a node/run. |
| 凭据 | Credential | Stored provider/application access configuration. |
| 工作区 | Workspace | The active dsh workspace/session storage. |
| 会话 | Session | The host conversation/session binding. |

Product and provider names remain unchanged: Workflow One, DSH, Feishu, Lark,
OpenAI, and DeepSeek Harness.
